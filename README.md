\# 💼 Sistema RBAC - TechSoluciones



Proyecto desarrollado en \*\*Django + Django REST Framework\*\*, que evoluciona un sistema básico de inicio de sesión hacia una plataforma completa de \*\*gestión de usuarios, roles y permisos (RBAC)\*\*, incluyendo \*\*auditoría de acciones\*\* y \*\*exportación de logs a CSV\*\*.

\## 🧩 Descripción general



Este sistema fue diseñado para la empresa ficticia \*\*TechSoluciones S.A.\*\*, con el objetivo de implementar un control de acceso flexible y seguro basado en roles (RBAC).



El sistema permite:

\- 🔐 Autenticación mediante login.

\- 🧠 Autorización por roles y permisos.

\- 📊 Registro de auditoría de acciones de los usuarios.

\- 📁 Exportación de logs de auditoría en formato \*\*CSV\*\*.

\- 🎨 Interfaz minimalista con \*\*TailwindCSS\*\*.
